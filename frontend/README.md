# MyRestaurant Docker

A containerized full-stack restaurant web application packaged with Docker and automated via GitHub Actions CI/CD.

## Features

- **Containerized Architecture**: Fully dockerized service setup for consistent deployment across local and cloud environments.
- **Modern Frontend**: Built with React, Vite, and modern tooling for high performance.
- **Automated CI**: GitHub Actions pipeline verifying successful Docker image builds on every push and pull request.

## Tech Stack

- **Frontend / Core**: React, Vite, JavaScript
- **Containerization**: Docker, Docker Compose, Docker Buildx
- **CI/CD**: GitHub Actions

## Getting Started Locally

### Prerequisites

- [Docker](https://www.docker.com/) and Docker Compose installed on your machine.

### Running with Docker

1. Clone the repository:
   ```bash
   git clone [https://github.com/jamespa001/myrestaurant-docker.git](https://github.com/jamespa001/myrestaurant-docker.git)
   cd myrestaurant-docker
   ```
